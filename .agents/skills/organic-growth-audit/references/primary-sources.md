# Primary sources and freshness

Checked **2026-10-11**. Reopen relevant current documentation for new platform-specific advice. Record redirects/removals; resolve conflicts using recency and specificity. This is not a crawler policy or permission to change one.

- [Google generative-AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide): normal SEO and original useful content matter. Google requires no special AI schema/chunking, ignores llms.txt for Search and documents AI reporting. Inspect what is actually available in the account.
- [AI features and your website](https://developers.google.com/search/docs/appearance/ai-features): indexed snippet-eligible pages may be considered; inclusion is not guaranteed. Search and training/grounding controls differ. Older reporting wording can differ from newer guidance.
- [Google documentation updates](https://developers.google.com/search/updates): FAQ rich results stopped appearing **2026-05-07**; documentation was removed in June. The former FAQPage guide redirects here. Useful FAQs/appropriate markup can remain without a rich-result promise.
- [JavaScript SEO basics](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics): Google renders JavaScript; distinguish crawl, rendering and indexing rather than declaring JS universally invisible.
- [Localized versions](https://developers.google.com/search/docs/specialty/international/localized-versions): check actual equivalent language URLs, reciprocal/self annotations and canonical choices.
- [Requesting recrawl](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl): requests have limits, do not guarantee indexing and do not accelerate crawling when repeated.
- [Lighthouse scoring](https://developer.chrome.com/docs/lighthouse/performance/performance-scoring): weighted lab scores vary; record versions and conditions.

For other engines use their own official inclusion/crawler documentation; Google's file/feature behavior is not universal. If current docs cannot be accessed, label the claim unverified and continue independent work.
